# 🧠 Personal Digital Twin

A **Personal Digital Twin** web application designed to track and analyze a student's learning activities, goals, progress, and overall performance.

The project creates a digital representation of a student's learning journey using activity tracking, goal progress, analytics, and a Digital Twin score.

## 🚀 Features

* 👤 Student profile management
* 📚 Learning activity tracking
* 🎯 Goal management
* 📈 Goal progress tracking
* 🧠 Digital Twin performance score
* 📊 Interactive analytics and charts
* 🤖 Intelligent learning recommendations
* 💾 SQLite database
* 🌐 Responsive web interface

## 🛠️ Technologies Used

* **Python**
* **Flask**
* **SQLite**
* **HTML5**
* **CSS3**
* **JavaScript**
* **Chart.js**
* **Jinja2**

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/PersonalDigitalTwin.git
```

### 2. Open the Project

```bash
cd PersonalDigitalTwin
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Virtual Environment

**Windows PowerShell:**

```powershell
venv\Scripts\Activate.ps1
```

### 5. Install Flask

```bash
pip install flask
```

## ▶️ Run the Application

Run the Flask application:

```bash
python app.py
```

The application will start at:

```text
http://127.0.0.1:5000/
```
